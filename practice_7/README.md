# PlutoChat: Приложение для обмена сообщениями через радиосвязь

## Описание

**PlutoChat** — это приложение для обмена текстовыми сообщениями через радиосвязь между двумя устройствами **Adalm Pluto SDR** с использованием библиотеки **libiio** (0.x версия). Оно поддерживает передачу и прием сообщений в реальном времени, используя многопоточную архитектуру для одновременной работы передатчика и приемника.

## Особенности

- Установка соединения между двумя устройствами Adalm Pluto SDR.
- Обмен текстовыми сообщениями через радиосвязь.
- Реализация многопоточной архитектуры для одновременной работы передатчика и приемника.
- Возможность настройки параметров радио (частота, полоса пропускания, усиление).
- Поддержка корректной доставки сообщений и их отображения в консоли получателя.

## Установка

1. Установите библиотеку **libiio** версии 0.x:
   - Для Linux (например, Ubuntu):
     ```bash
     sudo apt-get install libiio-dev
     ```

2. Настройте параметры радио на устройствах **Adalm Pluto SDR** (частота, полоса пропускания, усиление).

3. Соберите и запустите приложение **PlutoChat**.

## Пример использования

После настройки соединения между двумя устройствами, запустите приложение на обоих устройствах. В одном из терминалов будет выступать передатчик, а в другом — приемник. Отправленные сообщения будут отображаться на консоли получателя в реальном времени.
