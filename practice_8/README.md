# QPSK Simulation and Transmission with SDR

## Описание

В этом проекте была проведена симуляция **QPSK (квадратурной амплитудной модуляции)**. Входные биты преобразуются в значения {-1, 1}, затем выполняется оверсэмплинг с нулевым заполнением для I и Q компонент. Используется фильтр с АЧХ {1, 1, ..., 1} для сглаживания данных. Результат масштабируется для достижения амплитуды \(2^{11}\) и сохраняется в формате `int16`. Полученные данные сохраняются в файл `scam.txt`, а также визуализируются графики, включая исходные биты, данные после оверсэмплинга, отфильтрованный сигнал и созвездие QPSK.

### Ключевые этапы симуляции:

1. **Преобразование битов в символы**:
   - Входные биты преобразуются в значения {-1, 1}.
   
2. **Оверсэмплинг с нулевым заполнением**:
   - Выполняется оверсэмплинг для I и Q компонент.

3. **Применение фильтра**:
   - Используется фильтр с АЧХ {1, 1, ..., 1} для сглаживания данных.

4. **Масштабирование данных**:
   - Данные масштабируются для достижения амплитуды \(2^{11}\) и сохраняются в формате `int16`.

5. **Визуализация и сохранение результатов**:
   - Результаты сохраняются в файл `scam.txt`.
   - Визуализируются графики:
     - Исходные биты
     - Данные после оверсэмплинга
     - Отфильтрованный сигнал
     - Созвездие QPSK

## Пример использования

1. Скомпилируйте и запустите программу для симуляции QPSK.
2. Программа выполнит преобразование битов, оверсэмплинг, фильтрацию и масштабирование данных.
3. Результаты будут сохранены в файл `scam.txt`.
4. На экране отобразятся графики, включая созвездие QPSK.

## Выводы

В ходе выполнения проекта была разработана программа, способная взаимодействовать с SDR-устройством для передачи и приема **QPSK** сигналов. Эта симуляция позволяет лучше понять основы цифровой модуляции и использовать полученные результаты для дальнейшей разработки SDR-программ.
