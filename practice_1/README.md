# Работа с блоками QT GUI Range и PlutoSDR Source

## Шаг 1. Работа с QT GUI Range и PlutoSDR Source

1. Выведите на рабочую область GNU Radio два блока: **QT GUI Range** и **PlutoSDR Source**. Настройте значения блока QT GUI для установки нужного диапазона:
    - **QT GUI Range** — это слайдер для плавного регулирования величины, например, частоты или уровня сигнала. Блок визуализации создает значение переменной для проекта GNU Radio, но не имеет коннекторов.

2. Настройте блок **PlutoSDR Source**:
    - **IIO**: IP SDR — его можно узнать в файле `config.txt`, доступном на подключенном устройстве (отображается как флешка).
    - **Sample Rate**: `int(2e6)`.
    - **RF Bandwidth (Hz)**: `2000000`.
    - **PlutoSDR Source** — это блок для работы с недорогим SDR устройством, основанным на AD9363, производимым Analog Devices.

3. При корректной настройке при запуске (“Run”) отобразится график радиосигнала.

---

## Шаг 2. Добавление блоков QT GUI Frequency Sink и QT GUI Time Sink

1. Добавьте блоки **QT GUI Frequency Sink** и **QT GUI Time Sink** на рабочую область и соедините их с блоком **PlutoSDR Source**.
    - **QT GUI Frequency Sink** — визуализирует спектр сигнала.
    - **QT GUI Time Sink** — отображает сигнал во временной области.

2. После настройки появятся два дополнительных графика радиосигнала.

---

## Шаг 3. Добавление блоков фильтра

1. Добавьте на рабочую область блок **Low Pass Filter**, настройте его параметры и соедините с блоком **PlutoSDR Source**:
    - **Low Pass Filter** — фильтр для подавления высокочастотных составляющих, основанный на FIR-фильтрах.

2. Подключите к фильтру следующие блоки:
    - **QT GUI Frequency Sink** и **QT GUI Time Sink** для визуализации обработанного сигнала.
    - **WBFM Receive** — иерархический блок демодуляции FM-сигнала, преобразующий комплексный сигнал в демодулированный аудиосигнал.

---

## Шаг 4. Добавление блока Audio Sink

1. Добавьте блоки **Audio Sink** и **QT GUI Frequency Sink** на рабочую область и соедините их с выходом блока **WBFM Receive**.
    - **Audio Sink** — обеспечивает вывод звукового сигнала на аудиоустройство компьютера.

2. Полная схема теперь должна содержать блоки для визуализации и воспроизведения радиосигналов.

---

## Вывод

При правильной настройке всех компонентов:
- На графиках будет отображаться визуализация нескольких сигналов в спектральной и временной областях.
- Вы сможете обнаружить и воспроизвести звуковое сопровождение радиосигнала.

Этот проект демонстрирует базовые принципы работы с GNU Radio, включая настройку блоков, визуализацию спектра и временного сигнала, а также обработку и воспроизведение радиосигналов.
